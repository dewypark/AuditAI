## 프로젝트 전체

두이: 취업/제품 목표·우선순위·업무 범위 결정, Case 01/02 및 04–08 안내 기반 실습과 결과 확인, Case 03 부분 실습. 신규 통합본 시연과 전체 결과 검증은 패키지 실행 후 진행할 일입니다.

AI: 실습 안내와 예제 생성, 검사 함수 및 통합 Flask 화면 구현, SQLite 저장·검토 이력·내보내기·테스트 코드 작성/실행, 문서 초안 작성.

앞으로 두이: 합성 예제로 통합본을 시연하고 예상 결과와 대조; 대표 코드를 직접 수정하고 오류를 잡아내기; 각 Case의 검사 기준과 증빙에 근거한 감사 판단 설명. 고객 감사 경험·상용 서비스 운영 경험·독립 SQL 구현 완료로 표현하지 않습니다.

## 포트폴리오 소개 문장

> 합성 HR·ERP 자료를 활용해 Excel과 Python으로 퇴사자 계정 및 권한 관리 검사 예제를 수행했습니다. 생성형 AI의 도움을 받아 8개 감사 분석 Case를 Flask 앱으로 통합하고, 검사 기준·원본 참조·예외 검토·증빙 기록·작업조서가 이어지는 감사 지원 MVP를 구성했습니다. 직접 수행한 분석 실습과 AI가 구현한 웹/통합 기능을 구분해 기록하고 있습니다.

위 문장에서 통합본의 사용자 검증을 완료했다고 주장하지 않습니다. 두이가 실제 검증을 마친 후 검증 범위를 추가합니다.
